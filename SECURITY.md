# Security Policy

## Reporting Security Issues

The Inspektor Gadget maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/inspektor-gadget/inspektor-gadget/security/advisories/new) form.

For more details, see the [Inspektor Gadget security policy](https://github.com/inspektor-gadget/inspektor-gadget/blob/main/SECURITY.md).
